# Planning Pack

This directory captures the current v1 design for the AI-assisted development framework.

Read in this order:
- `docs/vision.md` - product scope, goals, constraints, and success criteria
- `docs/tech-stack.md` - proposed implementation stack for v1
- `docs/cli-contract.md` - behavior of the user-facing CLI
- `docs/git-storage-model.md` - how `.opencode` is stored and versioned
- `docs/devcontainer-strategy.md` - devcontainer detection, generation, and launch model
- `docs/runtime-layout.md` - generated files, runtime data layout, and `.env` semantics
- `docs/security-model.md` - mount permissions and security-sensitive rules
- `docs/implementation-roadmap.md` - decomposed execution plan for implementation

Intended use:
- product alignment before coding
- step-by-step implementation by a coding agent
- review of assumptions and acceptance criteria for v1
